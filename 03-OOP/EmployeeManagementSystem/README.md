# Employee Management System (Java)

A simple menu-driven Employee Management System developed in Java using Object-Oriented Programming (OOP) concepts. The application allows users to add different types of employees, view all employee records, and search employees by their Employee ID.

## Features

- Add Employee
- Support for different employee types:
  - Manager
  - Developer
- View all employees
- Search employee by Employee ID
- Duplicate Employee ID validation
- Menu-driven console application

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Method Overriding
- Runtime Polymorphism
- Constructors
- Arrays of Objects
