# Bank Management System

## Description
A menu-driven Java console application that simulates a basic banking system using Object-Oriented Programming (OOP). Users can create bank accounts, search accounts, deposit money, withdraw money, and view all account details.

## Features
- Create a new bank account
- Search account using account number
- Deposit money
- Withdraw money
- View all accounts
- Validations for duplicate account numbers and account types

## Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Arrays of Objects
- Methods
- Getters and Setters
- Menu-driven Programming
- Input Validation

## Technologies
- Java
- VS Code
